# ChallengerOneApp

Android e-commerce sample application demonstrating modern Android development practices.

## Tech Stack
- Kotlin
- MVVM architecture
- Coroutines
- Retrofit
- Jetpack components
- Clean Architecture principles

## Features
- Product listing
- Cart management
- State handling
- API integration

## Purpose
This project is a sample app created to demonstrate Android architecture, state management, and Kotlin best practices.
